# 前台还原与维护约定

前台使用原项目经确认的页面结构、配图、字体、间距、颜色和响应式规则。React / Next.js 负责服务端输出、路由和交互，FastAPI 提供目录、账户、积分、提交和检测数据。后台继续使用独立的橙蓝管理样式。

- `web/src/presentation/templates/`：从原版提取的展示函数，按导航、目录、账户、福利、检测和报告分文件。无原型的自动执行、模拟登录、模拟检测或本地积分发放代码。
- `web/src/presentation/styles/`：原样式按原加载顺序迁移，限定在 `.public-site`，管理样式限定在 `.platform-site`。不要在全局增加覆盖前台的表格、按钮或字号规则。
- `web/src/presentation/render.mjs`：公开路径、真实数据到原展示结构的适配及业务文案。来源快照保持来源日期，未检测或缺失价格不生成分数或零元报价。
- `web/src/components/public-server.tsx`：读取公开数据并输出服务端页面；禁用 JavaScript 仍有正文。页面元数据、canonical、noindex 和重命名跳转沿用 Next.js 路由约定。
- `web/src/components/public-controller.tsx`：真实接口和交互。原版模板中的输入控件使用原生 input / change 委托；React 自己生成的搜索框保持 React 事件，避免展示模板字段无法触发 change 插件。
- `web/src/presentation/report.mjs`：实际执行证据到原版报告的适配。失败请求显示失败报告，未取得得分时不显示零分；指纹未接入校准库时不产生候选概率。
- `shared/candy-questions.json`：与原版 20 道题一致的固定题库；公开检测支持 5 / 10 / 15 / 20 题。

`scripts/migrate-public-presentation.cjs` 是迁移工具，读取上级目录的原项目，生成普通源代码和本地素材。应用运行和生产构建只依赖本工程，不加载旧网页或运行旧脚本。迁移后的展示文件作为本工程源代码继续维护。工具默认拒绝覆盖现有文件；只有显式传入 `--overwrite` 才会重新生成并丢弃后续调整，正常开发不需要运行它。

## 核对方式

`node scripts/verify-public-parity.cjs` 对照旧原型 4173 和新前台 3001。可通过 `REFERENCE_URL`、`PUBLIC_URL` 指定地址。覆盖首页、目录、详情、登录、开发者、糖果、指纹、价格与福利，分别检查桌面／手机、浅色／深色，共 36 组。核对宽度、字号、字体、字重、颜色、背景和圆角，另核对首页及详情的关键桌面位置与高度，并检查横向溢出。

结果为 `verification/public-parity.json`，共 184 处元素通过。该检查验证关键元素样式与几何，不代表所有像素完全相同；实际分数、账户数据与原型演示文案会有合理差别。

9 项浏览器测试覆盖公开页面的服务端正文与 SEO、搜索与手机导航、两个后台、目录发布和改名、报告链接和二维码海报、模型筛选、客户端配图切换、报价筛选、指纹方式切换、自动获取模型与真实题量提交。6 个登录后个人页面另已逐页检查，无浏览器运行错误。

## 2026-11-25 交互与目录调整

首页模型入口使用 `/models/openai/`、`/models/claude/` 等独立模型详情路径，先展示模型资料，再展示“支持该模型的服务商”。主入口与手机“更多”使用相同映射；8 类模型在禁用 JavaScript 时也输出完整匹配服务商和独立 canonical，详情页允许索引。普通站点筛选仍可通过 `/stations/?model=...` 访问，筛选页保持 noindex。目录的重复介绍区已删除，公开页面不展示 VeriDrop 名称与链接；原始资料的日期及快照属性继续准确显示。桌面顶部菜单使用导航分组内的绝对定位，手机端沿用展开布局。

此前 36 组原版对照是还原时的验收记录。上述用户要求的变化有意区别于旧原型，当前用 `web/tests/ui-fixes.spec.ts` 检查导航位置、8 类模型详情及完整服务商匹配结果、公开展示清理及后台下拉交互。全部浏览器测试当前为 16 项。

## 模型选择与品牌图标

`web/src/presentation/model-catalog.mjs` 集中维护品牌识别、官方品牌图形文件映射和公开型号去重。前台选择建议由后台「站点与模型 → 常用模型」（`/admin/models/suggestions/`）维护，首次初始化 52 个常用型号，可新增、编辑、启停、删除与批量修改状态及排序。前台依次展示 GPT、Claude 等品牌，同品牌内按排序升序排列；官方图形自动识别。完整报价与来源型号仍用于搜索和价格页，不会因建议精简而删减。

公共目录接口仅返回启用型号，保存操作通过事务缓存队列自动刷新中英文服务端正文。明确配置为空时不回退全量；初始化标记保证删除或停用后重启不会还原。型号权限独立纳入 RBAC，只有读取权限不能写入。自定义角色需自行授予对应权限；已有自定义权限不自动扩大。

型号 ID 原样提交，不把出现在目录中视为当前 Key 有调用权限；通过 Key 发现的完整可用列表不会被后台建议限制。无法确定品牌的自定义或来源别名使用通用图形，避免错配官方标志。`shared/common-models.json` 是一次性初始化与旧接口升级回退共用的默认清单，日常维护在后台完成。

2026-11-25 按需求扩充为 52 个常用型号，补入 GPT 6 / 6.1 / 6.2、Fable 5 / 5.1 / 5.2、Opus / Sonnet / Haiku 5.5，以及近期 Gemini、DeepSeek、Qwen、Kimi、GLM、豆包、MiniMax、MiMo 等。型号拼写核对了导航站当前公开资源 `https://www.veridrop.cn/assets/index-vqpHzOrN.js` 中的目录及报价 ID；该资源未列出 Fable 5.5，不自行编造别名。旧 GPT 5 等建议在当前后台停用保留；默认清单只用于新库初始化，不在重启时覆盖运营配置。

首页、基础检测、糖果和指纹页面通过 `renderModelField` 输出同一原生输入框与 datalist；无 JavaScript 可填写或使用浏览器建议。`public-model-picker.ts` 增强为带图标的可搜索弹层，负责键盘、选中、按批滚动、定位与事件清理；样式仅在 `styles/model-picker.css`。Key 获取结果更新同一个选择器，提交准确的所选 ID。搜索和报价表格共用品牌识别，素材及 MIT 来源记录位于 `web/public/assets/brands/`。


## 模型大全、模型套餐与来源更新（2026-11-25）

顶部模型菜单改为「模型大全」和「模型套餐」。`imported-catalog.mjs` 与独立作用域的 `imported-catalog.css` 负责目录、筛选及详情展示，页面由 Next.js 输出服务端正文。保留原有 8 个模型生态详情链接和后台维护的常用模型建议。

模型目录使用 `/models/`，型号详情使用 `/models/{来源稳定标识}/`；套餐使用 `/coding-plans/`，产品详情使用 `/coding-plans/{厂商}/{产品}/`。路径标识统一为小写短横线，不随展示名称编辑而改变。独立详情带 canonical、描述、结构化数据和站点地图；搜索筛选组合不索引。来源已有的英文模型说明直接使用，套餐英文未完成前不对英文页面开放索引。

采集适配器位于 `api/app/collection.py`，固定读取 Hvoy 公开模型目录、公开分页接口和每组套餐详情。首次导入 656 个模型、86 家发行商、32 组产品、125 个套餐档位。模型保存参数、能力、官方价格与来源最低报价；套餐保存全部档位的原币种价格、计费周期、额度、支持模型、工具和备注。年付显示全年总价，估算额度明确标注；不把来源最低价当成本项目实测结果。

后台入口为「数据采集 → 数据采集任务」（`/admin/collection/tasks/`）与「采集运行记录」（`/admin/collection/runs/`）。可选模型/套餐、仅手动、间隔执行、每日定时或五段 Cron，统一北京时间，最短更新间隔一小时。初始任务保持仅手动，定时需服务器持续运行 `python -m app.worker`。手动运行也进入持久队列，由 worker 执行，不占用页面请求。

所有选中资料读取并通过完整性校验后，在一次事务中发布和刷新缓存；分页重复、缺少套餐档位或来源请求失败均保留旧版资料。模型/产品名称、简介与展示状态可在后台编辑，默认采集保留人工修改，也可选择跟随来源覆盖。新增模块权限纳入 RBAC，现有自定义角色需要主动授予采集与运行权限。


## 具体模型的中转站列表与套餐详情调整（2026-11-25）
