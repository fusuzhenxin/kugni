## 使用入口

## 实现边界

- 适配标准 New API / One API 管理接口，不执行任意供应商网页脚本或绕过 CAPTCHA、Turnstile、二次验证。创建远端令牌采用稳定名称；重试复用已存在令牌，并同步其完整 Key。远端明确停用或过期的令牌报告错误，不擅自重新启用。余额按站点 Quota 比例换算，不自动换汇；模型发现失败另记协议错误。
- 自动创建的标准令牌使用远端不限额度设置，不代表增加账户余额。建议使用专用探测账户控制可消费总额。默认不启用定时同步。
- 指纹使用版本化 14 维数字频率与顺序特征，训练与校准样本分开。API 模式只对照同协议基线；手动复制样本的采样设置可能不同。匹配有未知拒绝条件，相似度不是身份概率；没有真实可信源时库保持为空，不预置推测结果。
- 四协议为 Chat Completions、Responses、Anthropic Messages、Gemini。TTFT 为请求开始至首个非空文本片段；速度为服务商报告输出 token 数 / 首末文本片段间隔，含网络和分块影响。无 token 用量或仅一个文本片段时不估速，不能当作纯模型推理吞吐率。
- 自动发码是预先导入的兑换码、卡密或权益凭证，不包含供应商自动开户、在线充值或付费网关。用户只能读取自己的凭证。积分、库存和发放在同一事务中处理，失败回滚；实际无可用码时不扣分。
- 验证码绑定邮箱、10 分钟有效、最多五次错误、单次使用，数据库保存服务端密钥 HMAC。按邮箱与 IP 限频。验证码支持 587 STARTTLS 和 465 TLS；未接真实 SMTP 时不能验证送达。
- 本机已启用 GeoLite2 City（2026-11-25，50,531,001 字节），公开 IP 解析验证通过，来源与归属见 `storage/geoip/SOURCE.md`。地区只从本地库查询，IP 不存入统计事件。内网、旧事件及缺失地区显示未知。正式服务器需复制 MMDB 至持久卷并设置 `GEOIP_DATABASE`，数据库需定期替换更新。
- 自定义角色不会自动增加权限；管理员需按需分配新模块及关联 Key / 权益操作权限。初始超级管理员随 seed 获取新权限。
