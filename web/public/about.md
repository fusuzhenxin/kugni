# KUGNI

Website: https://www.kugni.com/

KUGNI 帮助用户发现 AI API 服务商，核对模型、公开报价、服务政策与来源公告，并查看接口检测证据。

KUGNI is an AI API discovery and comparison website. It provides provider directories, model specifications, published pricing, subscription plans, source announcements and API test reports.

## Interpreting the data

Published source statistics and KUGNI test results are presented separately. A provider's group success rate does not establish the success rate of every model in that group. Missing observations remain unknown. Ordered call samples without individual timestamps are labelled as recent calls rather than a historical timeline.

Pricing may use money, ratios, per-request billing or dynamic rules. Currency and billing units must be verified before prices can be compared as monetary amounts. Check the linked provider source for current policies and terms.
